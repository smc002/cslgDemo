## 核对依据

- 阅读当前工程 README、游戏设计、MergedPanel、HuntPanel、全局导航、CoreEnergy 和猎场模拟参数。
- 搜刮：九人三路自动战斗；重新布阵、1/2/4 倍速、连续挑战。
- 猎场：场内自由移动僵尸、小型装甲车与矩形安全高台；自动开火、1/5/20/100 倍率。
- 全局：能量核心栏、搜刮／猎场／英雄／内城四入口。
