先给判断

静态的主城，是大地图上的身份锚点。
列车可以动，玩家的“家”要能被找到。

如果后期希望保持接近这类 SLG 的联盟聚居、迁城、主城防守与集结习惯，建议把驻地和远征队列分开表现。战斗列车出发以后，地图上仍留下可辨认、可交互的玩家主城。

优先考虑 B「驻泊列车城」

用列车表达家园，用短编列车表达远征；原址保留指挥与生活编组。若更重视传统 SLG 的理解成本，选择 A「铁路营地」。若坚持所有火车都必须沿真实铁轨行进，则需要评估 D 的铁路网络规则。

这是结合截图与本项目设定提出的设计判断，不是对竞品内部规则的完整复刻。四版概念图已完成并经过检查，点击查看 A–D 概念图与检查结果；尚未修改战斗玩法。

02 / 转译到末日列车

先把三种对象拉开差别

以下均为本项目建议。欧卡表现延续上一轮的圆润体块、夸张轮廓、暖灯与明亮点色；末日感主要来自废墟、补丁装甲、植被侵蚀和感染区域。

对象首先要看懂建议的外观与信息要避开的混淆
玩家主城是谁的家，处于什么状态紧凑且可重复铺放的基座；一个主轮廓；联盟旗、昵称、等级；驻停、护盾、被攻击的简洁状态。普通出征后整座城市消失；高级城市无限加长，遮住邻居。
集结出征谁发起，去哪里，何时到达小型列车／车队＋有方向的线路＋队长标识；选中时显示倒计时、成员与兵力。集结队列的旗号和头车比单人队列突出。所有盟友直接奔向目标，却没有集合过程；每个成员都显示整座主城。
NPC／公共城市是什么目标，有多重要，谁占领更大的建筑群、专属地标、固定城名和等级；未开放、可进攻、争夺中、占领后有不同状态。只把玩家主城放大染红；中立与联盟占领使用同一种信息牌。

镜头与缩放

常规观察：约 35–50°俯视，以能辨认车头、车顶和基座为准；这是建议范围，不是对竞品镜头的测量。

拉远：保留领地色块、城市图标、干线和重要队列。中景：主城模型＋代表行军单位。拉近：少量站台生活细节和英雄身份。完整射击表演放在独立列车战斗层。

同屏识别

车体可统一使用青绿与暖橙，敌我关系由旗帜、边框、线路形状和文字共同表示。友军与敌军线路用冷暖色区分，同时保留箭头方向，避免只靠颜色。

普通队列短，集结队列稍长；成员数进入标牌，不靠车厢无限增长。英雄可用队长头像或车顶代表人偶，详细阵容在选中面板查看。

集结应该看得到一个完整过程

  1. 01发起领队驻地出现集结旗和倒计时
  2. 02汇入盟友小队到领队驻地；区分在途与已到
  3. 03出发合并成一支联盟代表队列
  4. 04抵达切换攻城／战斗状态，归属与计时可见
  5. 05返回解除集结，各成员队列返回各自驻地

上面是拟采用的表现流程。取消集结、迟到成员与已出征英雄的占用规则，细化时仍需明确；大地图不会同时把同一英雄显示在驻地和远征甲板上。

03 / 四版文字方案

四种“家”，带来四种世界气质

四版都保留可找到的静态玩家主城。差异主要在于：家是什么、出征什么、铁路是否影响规则。选择按钮仅切换阅读范围。

A
最接近传统 SLG

铁路营地

固定的家，出征的队伍

玩家在废弃车站建立固定幸存者营地；列车承担远征和近景战斗，主城承担建设、防守与联盟聚居。

想象这一屏

把镜头拉到约 45°俯视：一片灰绿荒原上，分布着一座座暖光营地。每座营地都被集装箱墙围成紧凑的方形，中央是一座高高的能源烟囱，一侧伸出短站台和车库。营地间有荒废公路与旧铁路线。远处的大型车站城市明显比玩家营地更宽、更高。

静态玩家主城

主城外观是“车站＋能源塔＋两三间生活建筑”，列车只占一侧。低级用篷布、铁皮与木栅栏；高级增加装甲门、吊机和温室，保持同一占地骨架。待机只有灯光、烟气和少量修理动作。昵称、联盟旗与等级固定挂在主城上。

集结与出征

盟友派短小的支援车队汇入发起人的营地，站台上亮起集结信号。倒计时结束，一支带联盟旗的远征车队离站；大地图只显示一个主模型和队伍数量。到达铁路战斗区域后，英雄登上战斗列车，接入上一轮的列车近景。

出征后，家还剩什么

整个主城保留，出发车库出现空位和“远征中”状态；城防、建设和资源仍挂在原坐标。其他队列可从同一营地继续出发。迁城是单独的搬迁操作。

NPC 城市

废弃站镇 → 尸潮占据的工业城 → 中央铁路都会。分别突出水塔、冷却塔、钟楼车站；城墙与厂区随等级增加。夺回后熄灭感染烟雾、点亮路灯并升联盟旗，地标本体仍然保留。

列车怎么到达目标

常规大地图可用公路车队处理任意方向出征，列车用于有轨区段。要接受“远征交通工具”与“近景战斗列车”并非同一个模型；用站台换乘交代转换，不让铁轮列车直接穿越草地。

收益与取舍

玩法和主城防守逻辑最容易解释；代价是大世界第一眼更像末日营地，列车主题主要集中在出征入口和战斗层。

适用前提

适合优先保留 COK 式迁城、围城、联盟聚居与多队列习惯。

下一步值得画什么

先细化一座中级营地、离站车队、工业 NPC 城，并画一张联盟聚居局部。

B
建议优先细化

驻泊列车城

家就是一列停下来的生存列车

主城由驻泊列车和展开设施组成；生活与指挥车厢留驻，英雄带可分离的短编战斗列车出征。

想象这一屏

同样是 45°俯视，但地图上最先看到的不是方形城堡，而是一列列短而厚重的末日列车。它们斜停在小型轨道基座上，生活车厢向两侧展开平台，形成紧凑的菱形营地。车顶种着小片绿植，天线、暖灯、布篷和修理吊臂带出“有人生活”的感觉。

静态玩家主城

中央是高大的指挥／能源车厢，两侧附着宿舍舱和储物舱；车头朝向统一的画面斜上方。用“车头轮廓＋核心高塔＋展开平台”确保缩小后仍像列车城。升级增加装甲和层数，不无限加长占地。皮肤改生活舱主题，保留车头、站台和身份牌。

集结与出征

支援小编组驶入发起人的驻泊站台，抵达后收拢为集结人数与旗帜，不把几十辆车首尾真实拼接。出发时展示一台强化车头＋少量战斗车厢＋联盟旗，点击才展开所有参战玩家与英雄。近景战斗再切到开放甲板，英雄向周围僵尸开火。

出征后，家还剩什么

指挥、能源和生活车厢留在原地，只有战斗编组离站。基座、围栏和主城名牌始终存在；空出的战斗泊位清楚表达“主力外出”，不能表现成整个账号的城消失。多队列分别对应不同远征编组。

NPC 城市

玩家是短小的列车城，NPC 是占据整片街区的固定废城：感染站镇有封死站房与残车；工业城有轨道机库和冷却塔；最终城市是环形编组场包围的大型中央终点站。夺回后修复灯带、恢复站台秩序，形成从废墟到据点的反差。

列车怎么到达目标

若要保留接近 COK 的自由出征范围，需明确战斗列车具备公路／轨道双模底盘：无轨地面落下大轮组，有轨区域收起并沿铁路走。路线箭头是信息叠层，不是凭空长出的铁轨。若坚持纯铁轮真实火车，则应转向 D 的铁路网络规则。

收益与取舍

主题连续性最好，也最接近参考图“移动家园”；需要讲清楚家用编组与战斗编组，以及双模底盘。美术上也要避免变成过长、互相挤占的细条城市。

适用前提

适合把火车作为品牌识别，同时继续采用固定玩家坐标、普通集结和多队列的大世界。

下一步值得画什么

优先细化“驻泊／集结／离站”三态，再画同一镜头下的玩家列车城与两级 NPC 城。

C
参考图的体量感最强

陆行堡垒

公路上的装甲移动家园

把参考图里的层叠住宅做成驻停的巨型履带堡垒，出征的是小型武装车队。火车近景需相应转成公路战列车。

想象这一屏

灰黄荒野上停着一座座厚重的陆行堡垒：底部是双履带，上方叠着驾驶室、住宅舱和屋顶花园，外侧挂着钢板、绳梯与储油桶。支撑脚压在地面，边上铺开维修棚和沙袋。盟友聚集后像一片正在休整的废土车城。

静态玩家主城

主城是单个高辨识度的装甲车堡，方形占地、纵向堆叠，核心大灯和烟囱统一。小号堡垒是一层车屋，高级增加二层指挥舱和炮塔。驻停时收起履带尘土，展开支撑脚，保证“静态主城”语义。

集结与出征

各家驶出轻型装甲车到发起人的车堡旁集合；倒计时结束，以领队指挥车加两三辆代表车辆出征，余下成员用队伍标识表达。公路战斗中，英雄站在车顶或平板拖车上开火，保留上一轮的车上战斗观感。

出征后，家还剩什么

主堡垒一直驻停，出征车队从其车库驶出。只有触发迁城时，主堡才收腿、启动并离开；常规出征与搬家用完全不同的模型和提示。

NPC 城市

高速服务区堡垒、露天矿城、炼油厂都市。大型地标更偏塔罐、吊机和公路围墙；所有 NPC 城都是固定设施，控制关键资源。占领时修复灯牌与仓库、改变旗帜和驻军，不把城市也变成车。

列车怎么到达目标

履带和轮胎适合任意方向的地表行军，跨河走桥或用明确的渡运节点。无需为普通地图铺设密集铁轨，但需要重新定义“火车”是公路战列车。

收益与取舍

大型移动家园最容易出彩，地表行军也直观；代价是偏离真正的铁路列车，上一轮已形成的轨道设定需要调整。

题材最完整，规则改动最大

铁路枢纽网络

占领车站，控制通往世界中心的线路

玩家主城仍是静态铁路据点，但所有远征列车必须沿真实的线路与站点行动；NPC 城市就是铁路网的战略节点。

想象这一屏

远景是一片由粗细铁路连接的废土版图。玩家主城像小型支线车站，密集挂在联盟枢纽周围。中景能看到列车穿过桥梁、隧道和分岔口；地图中心是一座多条干线汇入的巨型城市。推进目标从“靠近某个坐标”变成“打开下一段铁路”。

静态玩家主城

个人主城是带侧线与车库的紧凑驻站营地。联盟区域预留多个泊位／支线入口，避免所有玩家挤占同一根主轨；升级增强站房与调度塔，主线通行区始终清楚。

集结与出征

成员列车沿支线到领队站集结，界面同时显示“加入中／已到站”。到时组成一个可识别的联盟远征编组，再沿干线前往目标。地图上按逻辑队列渲染代表列车，不模拟真实铁路追尾、会车与排队，除非以后明确要做这类玩法。

出征后，家还剩什么

个人站房、调度塔和生活车厢原地保留，列车离开泊位。迁城是迁驻另一个允许停靠的支线节点，需要新的落点规则，不能继续假设任意空格都能落城。

NPC 城市

支线小站 → 桥头关隘 → 工业枢纽 → 中央总站。小站提供补给，桥头城控制跨区，工业枢纽连接多条线，最终总站有大跨度穹顶和环形调度场。首次夺回可亮起相邻轨段，但实际开放规则需另外设计。

列车怎么到达目标

铁路是可通行规则本身，行军时间按线路长度计算；桥梁、岔路与枢纽影响路线。需要解决孤立玩家、远距离入盟、弱盟绕行和关键节点封锁，不能只画几条轨道就宣布支持自由出征。

收益与取舍

火车、集结和攻城目标互相支撑，差异化最明显；但这是玩法框架变化，会显著增加地图、迁城和联盟规则的设计成本。

适用前提

适合后期准备把铁路交通与区域控制作为核心卖点，单独验证世界规则。
