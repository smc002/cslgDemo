### 三段自由操作与引导强度

- 0–3分钟：只保留必要的单步强引导，首次布阵、首次命中、首抽与一次替换。对话可跳过。
- 3–10分钟：修厂与首次领取各一次；其余以目标条和小窗提示。只在首领等节点拦住自动推进。
- 10–30分钟：首次升星、三路换位复盘、一次建筑升级给局部提示；已完成的操作不重教。目标区只展示一个当前主目标。
- 10:00、16:50、20:00三段刻意保留较长自由空间。剧情只在开始/结束接一句，不从中间拉走玩家。

## 4. 故事怎样嵌入循环

玩家身份：曙光小队的新任指挥员。三位初始英雄负责动作和个性，新增维修员负责把基地修起来。不是每一步都靠旁白解释数值。

| 因果 | 画面能证明的事 | 任务文案示例 |
|---|---|---|
| 门口被堵，补给进不来 | 弹药箱在敌群后，营地灯灭 | 清开入口，取回弹药 |
| 有了黑金弹，可以启动高台火力 | 弹箱装载，枪口发射；高台保持安全 | 击破感染者，回收核心 |
| 核心让装备同步成长 | 光点飞入同一等级栏，三名角色Lv一起变 | 全队装备同步完成 |
| 援军回应求救 | 大刀战士通过电台接入 | 呼叫一位新伙伴 |
| 营地不能只靠捡弹药 | 回收站建材、停产厂房、维修员作业 | 修复弹药线 |
| 生产声响吸引尸群 | 工厂启动声、城外探照光扫过巨影 | 守住刚修好的家 |
| 终战胜利改变世界状态 | 灯光、旗帜、角色站位与机器运行 | 曙光营地，恢复运转 |

核心始终是共享成长资源，不在剧情中说成修厂要花的燃料；建筑消耗建材。电台接通是剧情表达，首版不要求实现通讯中心玩法。更详细的逐句台词、时长和资源编号见[剧情与美术需求](E:/cslgDemo/docs/onboarding-20260923/剧情与美术需求.md)。

### 序章首领：破门王（暂名）

外形：大块头感染者，交通护栏当盾，警示锥歪戴在头上；夸张、笨重、有压迫感，避免血腥写实。剪影必须与普通巨型僵尸不同。

第5关先使用现有巨型精英作为小头目；只用城外巨影埋下“破门王”的伏笔。第10关才正式登场，让新增造型有价值。

战斗沿用搜刮三路自动战斗：第三波首领主要压中路，一项明确能力是“举护栏蓄力→中路地面条带亮起→砸击”。玩家的决策发生在战前：中路安排能承伤的前排和治疗，侧路清完后真实支援。**不临时增加闪避键或战中拖动规则。**具体蓄力建议1.2秒、表现长度需随2/4倍速保证可读；伤害待实测。硬模式计时、第二套战斗系统不进入首版。

若提前通关，照常赢；若失败，显示哪一路先倒和一条有效建议，允许调整/成长后重试。不会把玩家强制判败来展示剧情。

## 5. 资源能否支持这个时长

当前普通射击4发/秒；第一关120弹仅支持**30秒**普通持续射击。Lv.1弹药厂每45秒15弹，即每分钟20弹，只支持每分钟5秒开火。因此“修厂后就能一直打”并不成立，主线首通仍是前期主要供给。

基础关卡奖励公式沿用：`120 + 15 × (关卡−1)`（前10关未触及增长封顶）。

| 供给 | 前30分钟预算 | 状态 |
|---|---:|---|
| 第1～10关首通 | 1875弹 | 已有规则；120+135+…+255 |
| 首次修厂目标 | 150弹 | 建议新增，一次性 |
| 第5关阶段目标 | 150弹 | 建议新增，一次性；不能重试刷取 |
| Lv.1工厂约03:50开始生产，到30:00 | 最多34批×15=510弹 | 按需领取且不撞20批容量；至少两次领取才能实现此上限 |
| 总供给示例 | 2685弹 | 不含应急、工厂升级增量、随机额外供给 |
| 表内普通射击目标 | 约565秒×4=2260弹 | 还需按时间检查余额；不是命中保证 |
| 理论余量 | 425弹 | 供漏枪、挑战或时长差异；不能提前使用未来关卡奖励 |

供给总量能支持约11分11秒普通射击；表内目标约9分25秒，留出余量，但这只是总量校核。第10关255弹要到27分钟左右才拿到，必须单独检查每段余额；20倍/100倍耗弹会改变预算，新手引导默认×1，不强制开高倍率。

建议在新手仿真中按每次入场/出场核对库存：第一次猎场≤80弹；修厂后的段落≤160弹；第5关之前其余主动射击≤80弹。到第5关时基础累计750弹、修厂额外150弹，按上述节奏有足够回旋空间。后续阶段遇库存不足时自动停止开火并给出已完成目标/可领取工厂/未通关搜刮入口。

首个200核心不能依赖随机爆大奖。建议首个猎场用受预算约束的固定教学目标，使玩家在80弹以内、常规命中情况下得到200核心；miss多时暂停新教学、保留当前步骤，允许领已得补给后继续。`ordinaryYield=5080`是经济账本预算参数，不代表每发立即获得5.08可用核心，不能直接拿它当升级实测速度。正式接入需校验命中、派生奖励和到账时机。

1000实际耗弹在4发/秒下至少需要约250秒付费普通射击；页面阅读、特殊免费弹不计入。运钞资格自然可能在中期出现，确切时间由操作决定。挑战所需击破资源仍要留足；资格不等于自动发卡。

### 建材与第二次建设

内城原有100建材全用于首厂。建议第5关阶段目标另给200建材。回收站约03:20开始工作，每30秒10建材，到19:00理论约310建材；中途领取避免20批封顶，加上阶段奖励共约510，足够指挥部Lv.2的300和弹药厂Lv.2的200。选择能源站Lv.1则花100，剩余建材继续保留。

因此19分钟的建设选择有实际资金依据；若玩家前面自由消费，提示差额并等待自己的产出，不偷偷负数建造。Lv.1→2仍用第一阶段建筑外观（现有Lv.1/4/8换外观），通过灯、运转和数值反馈展示提升，不承诺每级换新房子。

### 卡关与断弹

- 第1/2关用固定教学敌群、合理强度和阵型回退确保容易通过；不靠无敌文字掩盖伤害失效。
- 第一场明显难度节点前已完成工厂修复，设置中的应急补给在断弹提示中给直达入口。沿用80弹、3次、3分钟冷却；不能无限领取。
- 工厂待产、无应急、又卡关时，展示真实倒计时和阵型建议。若首次流程实测频繁落入此状态，调整关卡/固定补给，不让玩家以等待几分钟作为教学成本。
- 不复制录像的“资源不足即弹购买页”。此DEMO的补给去向应可玩、可理解。

## 6. 演出、引导与中断规则

| 情况 | 建议表现预算 | 行为规则 |
|---|---:|---|
| 普通命中 | 即时开始，局部约0.1～0.2秒 | 不阻断连续开火，枪口/弹道/命中同一条因果链 |
| 普通资源回流 | 0.4～0.7秒 | 数据先原子入账，视觉数值跟随归位；切页立即补齐显示 |
| 首次共享升级 | 2～3秒 | 显示三人同步；后续合并为局部横幅 |
| 首次援军 | 4～6秒，可停留阅读 | 一个职业、一个短技能；重复卡1秒汇总 |
| 首次升星 | 2～3秒 | 显示前后数值；不虚构外形进化 |
| 首领入场 | 2秒左右 | 停止后台自动挑战，玩家确认后播 |
| 首领胜利+阶段奖 | 3～5秒演出，阅读自由 | 共用一个结果面板，避免连续点三次领取 |
| 单段剧情 | 开场≤12秒，中段通常4～7秒，尾声≤18秒 | 点击可提前完成逐字、再次点击继续；统一跳过 |

完整序章强制剧情目标控制在约75秒以内。台词时长是阅读预算，需试玩验证；剧情框不要遮掉当前教学目标。

演出队列优先级：当前玩家操作完成 → 首领/失败处理 → 首次关键解锁 → 角色获得 → 共享升级汇总 → 普通奖励。奖励数据可以同时到账，画面不要同时抢占中心。

剧情/模态/切离猎场时停止自动耗弹，返回由玩家恢复；搜刮仍按既有后台规则推进。重要教学期间若后台达成下一里程碑，存为待展示项，当前操作结束后再处理。

刷新、关闭、切页：按已完成事件恢复，奖励发放和教程显示分别记录。教程被跳过后保留功能与目标，不反复补播。老档进入只提示“可回看序章”，不自动重置、不拿走已获得内容。

建议状态记录：序章步骤、已看剧情集合、里程碑奖励领取集合、定向招募消耗标记、升星教学补足标记、营地叙事状态。以业务事件推进，如首通、真实命中、核心到账、英雄获得、修复完成、首领击破；不能依赖动画播完才发奖。

## 7. 制作顺序与试玩验收

先做**0～5分钟完整样板**：开场、一次布阵、首战、黑金弹到猎场、核心到全队升级、剧情招募、救维修员、修厂并领第一批。跑顺这条链后，扩展第5关小高潮，再接第4关三路扩编和第10关终战。顺序按依赖制定，不是工期承诺。

| 阶段 | 可 review 的交付 | 通过条件 |
|---|---|---|
| A：节奏灰盒 | 新档流程状态与奖励表；现有素材+占位对白 | 行为触发顺序正确、随时刷新可恢复、没有重复奖 |
| B：首5分钟 | 开场分镜、基础引导、升级/援军/修厂演出 | 用户不看说明也能完成，资源去向可复述 |
| C：完整30分钟 | 扩编、升星、建设选择、首领、尾声 | 三段自由操作成立，失败有有效回路，结尾有下一目标 |
| D：表现与调优 | 正式美术、音效、真机录屏 | 竖屏可读、不误触、不被粒子遮住数字；实际耗时达到区间 |

建议首轮找5名没玩过本项目的人，记录事件时间、误触、求助、退出位置；样本只用于发现问题，不估计留存。需验证：

1. 首个有效操作≤20秒；首胜≤70秒；进入猎场≤90秒。超过后区分阅读、寻路、战斗和卡住的原因。
2. 约3分钟能回答“黑金弹从哪来”“核心让谁变强”；约6分钟知道哪里领工厂弹药。
3. 首10分钟完成至少一轮“搜刮→猎场→成长/英雄→搜刮验证”。第5关目标中位数8～10分钟；不强制拖慢熟练者。
4. 10分钟后至少有两段≥60秒不被强制切页的操作；普通升级、后台胜利不会反复夺焦点。
5. 任何时间段不能支出尚未取得的弹药/建材；断弹后能够找到下一有效动作。
6. 普通运气/较差命中、早抽到剧情英雄、跳过剧情、刷新、返回、失败重试均能继续主线。
7. 终战建议首次体验25～30分钟收束；若多人超过35分钟，优先检查资源和关卡长度，不能只缩短对白。

建议采集本地事件：首次输入、首胜、首次猎场命中、首次200核心、首抽、首次换位、修厂、首次领弹、第二/第三路、首次升星、1000实际耗弹、首次运钞击破、第5/10关胜利。每条记录累计游玩秒数、当前关卡、弹药/核心/建材余额及引导步骤，便于还原时长。

## 8. 这一版适合一起讨论的三项决定

1. **故事主轴**：推荐《夺回营地》，从救维修员和恢复工厂建立营地归属；也可改成先救幸存者车队，但会增加车队场景和人群资源。
2. **扩编节奏**：已确认第2关第二路、第4关第三路，第三路目标约7分钟；以事件推进，不强制等待计时。
3. **首次招募**：推荐单独标注“剧情援军”，确定获得大刀；若希望从第一次就随机，应允许任意结果继续，并另设计确定的新伙伴来源。

这三项未作为已批准规则写入运行逻辑。已确认的明亮末日风格与少量新增资源范围已反映在剧情和美术需求中。
