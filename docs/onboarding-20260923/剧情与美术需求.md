## 1. 世界与角色的第一印象

这是一个仍然能重新生活的末日。破败通过拼补钢板、旧路牌和杂草表达；希望通过运转的机器、打开的灯、小队互相照应表达。主要危机是营地失去补给，不用大段病毒历史开篇。

玩家是现场指挥员，不新增需要战斗动画的玩家角色。初始英雄继续用既有身份与配色，不改名、不改职业。新增一名非战斗NPC，序章首领新增一套身份。

| 角色 | 戏剧职责 | 语气与动作 | 首版美术范围 |
|---|---|---|---|
| 铁壁队长 | 建立安全感，让玩家敢行动 | 句子短、先挡再说；偶尔一本正经地接梗 | 原角色，补认真/吃力/安心表情 |
| 医疗兵 | 关心队友，也负责把“全队成长”说清楚 | 实际、温和、略带吐槽；不讲长公式 | 原角色，补专注/松口气/无奈表情 |
| 无人机手 | 指出目标，制造轻喜感 | 报数据很快，遇到意外会停顿；无人机亮灯呼应 | 原角色，补得意/惊讶/思考表情 |
| 大刀战士 | 第一位外来伙伴，证明援军呼叫有意义 | 可靠、直爽；用大刀开路，不长篇自我介绍 | 原角色卡面，补应答表情；战斗动作复用 |
| 阿栓，维修员（暂名） | 营地的生活气息与持续修复目标 | 有本事、嘴硬；把工具箱当宝贝 | 新增剧情NPC；不入卡池、不新增可玩职业 |

阿栓造型：成年维修员，圆脸，黄橙安全帽、青绿工作服、腰间工具；扳手、护目镜、工具箱形成剪影。与无人机手区分为“机械修理”而非“科技终端”。首版可用立绘与场景小像，不强求跟随玩家行走。

### 首领动作包先做哪些

首轮最低动作：待机4帧、移动8帧、举栏蓄力与砸击8帧、受击3帧、败退/倒地8帧，共31帧/源方向的预算起点；这不是要求把不自然的动作硬凑成31帧。先验证关键姿势，再决定帧数。

终战灰盒先统计首领实际攻击目标方向，再决定源方向数量。正面略俯视是基准；不能只做一套正面再宣称多方向完成。若只做固定中路位置与限定攻击角度，必须同步限制其逻辑，不能让角色横向滑行而仍朝下砸。护栏属非对称装备，镜像是否可用要在原图逐项检查。

第5关小头目用现有巨型怪，不提前消耗首领整套演出。破门王可在未来复用，但不为长线设定额外增加首版动作。

## 4. 场景分层与构图约束

外门镜头采用明亮卡通、略俯视，与现有猎场和内城接近。大面积低纹理路面承载战斗，两侧废车/围墙组织空间。营地入口既能看见危险，也要看见“值得保住”的生活痕迹，例如折椅、修补晾绳、小灯。

建议层级：远景树林/建筑 → 地面路径 → 后侧墙与大门 → 角色/敌人 → 低矮道具 → 前景遮挡 → 特效 → HUD。门、灯、电线、旗帜独立；“受损”和“恢复”状态只改相应层，不把整张背景换到不同透视。

第一版同时检查390×844和375×667竖屏：主按钮、引导句、返回、资源余额必须可见；人物半身不要压住需要拖拽的格子。原视频910×1600是参考录屏规格，不是本项目强制画布尺寸。

基地首次打开时仅突出回收站和弹药厂，已有其它建筑仍属于场景，可以查看但不同时冒新功能气泡。P1尾声暖光属于叙事状态，不能把所有建筑伪装成已升级到Lv.4/8。

## 6. 首版可裁剪与必须保住的部分

必须保住：首次命中→核心回流→全队升级、第一次新伙伴、工厂从停到动、首领预警→命中、营地最后亮灯。这五个可见变化是序章完成感的主要来源。

可先裁剪：全程配音、NPC完整行走、独立CG（用实景合照替代）、每个援军单独全屏演出、每级建筑换新外观、首领多阶段变身。不能用裁剪把关键操作退化成只有一行Toast。

建议第一轮先评审三份图：**外门受损/亮灯同镜头对照、阿栓身份草图、破门王剪影与举栏动作**；确认这三个视觉决定后，再批量做表情、图集和动效。当前文件是需求与台词，尚无这三份新图。

## 7. 讨论用的替代方向

- 如果希望更强的小队感：让阿栓负责生活笑点，末尾用实景合照，多给英雄互相回应；不新增可玩角色。
