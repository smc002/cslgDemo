# 猎场僵尸八方向与拖步返工

## 动作与视角

用户反馈旧动作像运动员，且各移动方向始终显示正面。本轮保留明亮卡通身份，重画低位拖步：普通僵尸塌肩跛行；装甲僵尸负重挪步；巨型僵尸沉肩弓背；爆炸僵尸背罐前倾。四拍不等时长，着地停留较长，拖脚换重心较短；不使用规则跑步摆臂、抬膝或全身旋转模拟朝向。

每套图集 2560 × 1600，单元 320 × 320，共 40 帧。五行依次为 S、SE、E、NE、N；每行四帧移动、三帧受击、一帧准备姿势。五个视角独立生成，SW/W/NW 由对应右侧视角水平镜像，总共覆盖八方向。四套基础动作由现有 12 种僵尸共享，功能配色保留。镜像会翻转衣物局部破损，当前远景接受这一取舍。

移动保持源图中低位接地、短步交换和不对称重心变化。受击从准备姿势进入上身反应、再恢复；同方向的骨盆、腿脚使用准备帧像素固定，遮罩避开低垂手臂或连同完整手臂固定。不得出现横切手套、重复靴子或透明接缝。

## 接入

- 当前资源入口：`public/assets/hunt/art.json` → `zombies-v3/manifest.json`。
- `hunt/zombie-animation.ts` 统一负责八方向选择、角度滞回、动作时钟、变速帧采样和镜像映射。
- `hunt/view.ts` 按实际速度向量选图集行。受击和冻结保留当前朝向与步行动作时钟；恢复后继续。死亡淡出及快递僵尸碎片保留死亡前朝向。
- 22.5° 分区边缘增加滞回：离开当前方向中心超过 30° 才切换，防止轻微转向左右闪动。
- 特殊僵尸头顶标签上移，避免覆盖头脸。
- 位移速度、伤害、掉落和受击判定时长保持现有逻辑。

## 追溯和复现

源图、完整提示词、裁切映射、统一缩放、固定下肢遮罩、逐帧及叠图记录分别保存于 `docs/art/hunt-zombies-v3/{normal,armored,heavy}`。生成由内置 imagegen 完成，后续脚本只拆分、透明处理、统一缩放及固定区域烘焙。

`public/animation-preview/hunt.html` 提供八方向、自动绕行、受击、冻结、暂停、逐帧与慢放；加载与猎场相同的清单。预览逻辑由 `node scripts/build-hunt-animation-preview.mjs` 从游戏源代码构建，避免另写一套朝向规则。

`node scripts/render-hunt-direction-review.mjs` 生成八方向静态对照和循环 GIF。GIF 展示实际图集帧，按每 80 毫秒采样步行，不代表完整浏览器游戏截图。

## 验证

- `scripts/test-hunt-directions.mjs`：当前四套 160 单元透明边界、五个源朝向及三向镜像、受击固定区域逐字节一致；八方向速度映射和滞回；实际渲染器 12 种 × 8 向的移动→受击→移动、冻结、死亡淡出、背面碎片。
- `scripts/test-hunt-production.mjs`：旧图集兼容、平台阻挡、炮口、里程碑等原有回归。
- `scripts/test-hunt-cadence.mjs`、`scripts/test-loop.mjs`：射击节奏和资源循环回归。
- TypeScript 检查及本地生产构建。

资产源图、接缝、叠图和缩小画面进行了人工图像检查；渲染器用 Node 调用实际方法验证。未进行浏览器自动化操作，不将这些结果表述为完整浏览器画面验收。

本轮上述四个回归脚本及 TypeScript 检查通过；本地页面、预览模块、当前清单和四张图集均返回 HTTP 200。Sites 构建包装器因环境既有 npm shim 路径缺失失败，改用项目自带 `node node_modules/vinext/dist/cli.js build` 完成生产构建。未部署。
