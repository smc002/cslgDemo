# 角色动画生产约束

适用项目：物资搜刮 2D 序列帧。2026-09-22 起，新角色及返工必须执行。本文件是生产与验收规范，不能只把约束写进生图提示词后直接入库。

## 一、先定义动作，再生成

每个动作记录：用途、朝向、准备／发力／恢复关键姿势、接触地面的部位、允许移动的部位、命中时刻、是否循环、返回的待机姿势。

| 动作 | 下肢约束 | 上身表现 | 根节点 |
| --- | --- | --- | --- |
| 医疗兵射击／治疗 | 双脚、膝盖、骨盆固定，复用同一下肢 | 举枪、轻微后坐、恢复 | 固定 |
| 无人机手普攻／指令 | 双脚、膝盖、骨盆固定，复用同一下肢 | 点击终端、抬手指挥、恢复 | 固定 |
| 持盾大汉盾击／格挡 | 本版双脚支撑不迈步，复用同一下肢 | 盾臂和躯干发力，恢复支撑姿势 | 固定 |
| 行走 | 明确左右脚接地和离地，不锁死下肢 | 自然摆动 | 位移由战斗程序驱动 |
| 死亡 | 允许全身倾倒 | 失去支撑、倒地、静止 | 不回弹、不循环 |
| 狙击射击 | 每个朝向独立固定支撑姿势 | 瞄准、后坐、恢复 | 固定 |

## 二、素材生产与拆分

1. 固定角色身份图、服装、比例、俯视镜头和光照，禁止逐动作重新设计角色。
2. 先检查准备、发力、恢复三个关键姿势。关键姿势不合格，不进入批量补帧。
3. 站定动作使用“固定下肢＋变化上身”加工方案。图集最终可以烘焙为整帧，但下肢必须来自同一份像素；不能依赖 AI 每帧重画出相同靴子。
4. 分层接缝放在腰带／衣摆遮挡处，上下身重叠，检查武器或手臂跨过接缝时是否被切断。不能用一条随意横线剪掉低垂的手、盾、枪。
5. 一组动作使用统一缩放。禁止按每帧包围盒分别拉伸到同样高度；这会把后坐、蹲伏变成身体缩放。
6. 固定画布、地面坐标、骨盆坐标与角色原点。标注枪口、枪管方向、命中帧，和图集一同保存。
7. PNG 保留真实透明通道和单元间隔；检查相邻格串图、细小漂浮像素、脚底残影。
8. 行走和死亡保留全身序列。已有合格片段可复用，不为凑帧数重新生成。

## 三、方向与战斗约束

- 固定镜头不代表角色只有一个朝向。先按战场目标角度分布制作方向集；本版狙击使用 N／NNE／NE／ENE／E／SE／SSE／S 八份源方向，镜像覆盖上、下、左、右及多个斜角。实际角度必须测量，不能用方向名称代替。
- 射击前选最接近目标的方向，发力到恢复期间锁定，避免左右闪烁。镜像是临时节省资源的方式，不适合必须保持装备左右手的特写。
- 枪口坐标与枪管轴线必须根据实际图片标注，不能按图片宽高估算。
- 弹道从当前帧的枪口出发。方向素材仍有残余误差时优先修正素材或小幅调整武器层，禁止大幅旋转整个人来追踪目标。
- 静止攻击期间程序不得额外播放行走帧、上下抖动、移动根节点；技能伤害只在命中帧结算一次。
- 切换方向仅在需要时发生，动画开始后不按微小位置变化不断重新选方向。

## 四、验收门槛

必须同时完成：

1. 原始尺寸逐帧：覆盖地面线、骨盆线，半透明叠图检查腿脚漂移、身体大小变化、接缝和装备变化。
2. 程序检查：固定下肢区域像素逐帧一致；画布与锚点一致；素材透明边界不串图；命中帧在合法范围。
3. 实际游戏尺寸：检查准备、攻击、回待机以及移动→攻击→移动的切换，不仅观看单段动画。
4. 多方向目标：检查上方、左右斜向和横向目标，比较枪管和弹道；枪口必须相连。发现方向误差大于约 22.5° 时不得声称已对齐。
5. 暂停／加速／死亡打断：不多次伤害、不复活、不死亡循环；跨路支援过程中不得滑着脚攻击。

## 五、可追溯交付

保存原图、完整提示词、源图到帧的裁切映射、固定下肢来源、接缝位置、统一缩放与锚点、枪口标注、检查结果。自动检查只证明对应数值条件，不能替代肉眼验收接缝和动作自然度。
