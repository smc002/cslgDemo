## 二、资源需要明确分开

1. 黑金弹库存：可以消耗；由搜刮关卡首通和内城产出。图标参考用户提供的黑金色三枚弹药图。
2. 能源核心：共享经验，自动累计推动全队等级与招募券进度，不分配给单独英雄。显示本级进度时扣除升级门槛不等于玩家主动消费核心；总获得量应单独保存。
3. 累计实际耗弹量：独立计数，不是黑金弹余额，也不是能源核心。免费射击、连锁派生弹不应复制库存消费记录。
4. 招募券：用于抽取英雄。
5. 建材：独立资源，由内城生产建筑产出，用于建筑建造和升级。解锁时免费修复工坊，并给一次足够建造首座黑金弹工厂的建材包。

此前旧猎场的细则包括“累计消耗 1000 库存弹产生一份运钞僵尸资格，完成击破后给橙卡”、装甲阶段和领取冷却。用户本轮确认保留累计耗弹机制；界面名称、具体门槛、演出是否完整沿用，后续单独复核。不能把达到累计耗弹门槛直接写成自动发卡。

## 八、英雄统一模型的设计约束

英雄定义需要保存 heroId 和初始品质（baseQuality）；玩家拥有的英雄保存当前品质（quality）、当前品质内星级（stars）与重复英雄进度。同一个 heroId 应贯穿收藏、升星进阶、上阵、动作和技能。初始橙色英雄获得时直接从橙色开始培养，不经历蓝、紫阶段。抽取品质与培养后品质需要分别显示；是否允许同一 heroId 在卡池中以不同品质出现、不同品质重复卡如何折算尚待确定，不能据跨品质培养自行推定。

界面应分别展示共享等级、个体当前品质、当前品质内星级，初始品质可在详情/图鉴中展示。抽到新英雄继承共享等级；已有英雄进阶不损失等级。红色已确定为最高品质；技能是否随品质解锁、每档最大星数稍后核对。首版优先用现有九个战斗职业建立统一英雄表，避免把二十张现有卡面当成已经完成二十位战斗英雄。
