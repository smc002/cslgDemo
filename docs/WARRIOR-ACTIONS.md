# 大刀战士动作样本 v5

参考 `C:/Users/hy/Desktop/cslg_img/2.png` 上半部分：红色莫西干头、红胡子、黑色铆钉护甲、骷髅腰带与红刃大刀。复用狙击手完整姿势序列帧流程，不使用 Spine。

## 动作设计

| 动作 | 表现 | 程序行为 |
| --- | --- | --- |
| 移动 | 持刀警戒、双腿交替迈步，8 帧循环 | 点击路面或 WASD 位移，持续转向，不在每次改变目的地时重置步态 |
| 普攻 | 预备、后引、蓄力、挥出、接触、随挥、收刀、复位 | 自动走近僵尸后播放，第 5 帧触发一次刀光和命中变色 |
| 重击 | 预备、屈膝、举刀、举至高点、劈落、触地、拔刀、复位 | 自动走近僵尸，第 6 帧触发一次地面冲击圈 |
| 死亡 | 失衡、屈膝、跪地、侧倒、落地、展开、静止、保持 | 保持第 8 帧，不再接受移动或攻击，Revive 后恢复 |

## 操作

双击同目录 `OpenPreview.cmd`。默认展示大刀战士；顶部 `Cleaver / Sniper` 切换两个角色。

- `Move` 或点击地面：移动。
- `Slash`：普通挥砍；`Heavy slam`：举刀重击。
- `Death / Revive`：倒地与复活。
- `Play all`：依次演示移动、普攻、重击、死亡。
- 保留角色大小 25%～200%、播放速度、暂停、逐帧和背景切换。

## 资源接入

四张原始透明图集在 `Assets/Mori2DValidation/Art/Warrior/`，每张 1774×887。完整提示词在 `generation-warrior-v5.json`。

`prepare_warrior_metadata.py` 只分析像素，不修改图片：根据两行动作间的透明空白，以及每行四个姿势之间的空白确定裁切边界。避免等宽裁切截断伸出的刀刃。移动帧以红色头发作水平对齐标志，其余动作以脚部区域定位；最终坐标存入 `Data/warrior-actions.json`。

`MoriActionLab` 加载两套动作数据，角色切换会清除上一个角色的位移、死亡与特效状态。`ActionLabBuilder` 导入和验证两位英雄共 64 帧，在同一个独立场景中接入。场景仍保留原路径 `Scenes/SniperActions.unity`，避免原入口失效。

目前仅一个斜背方向，左右采用镜像，非完整多方向素材。AI 图集各帧仍存在造型细节变化，需要以实际播放效果验收；此样本尚未接入正式关卡或 Android 真机。
