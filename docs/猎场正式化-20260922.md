# 猎场正式化 · 第一轮接入

2026-09-22。用户选定明亮卡通风格、高台安全区，并要求缩小车辆。此轮直接修改本地游戏，没有部署或提交代码。

## 界面与奖励

- 顶部标题改为“能量核心”；删除下方黑金弹、核心总数、票券及目标入口这一整行。当前目标移到设置。
- 能量条按真实累计核心的 200 点阈值显示票券节点。每级选择最多三个分布节点供快速查看；中途的每 200 核心奖励仍自动到账。点击节点可查看接下来的三次奖励，不需手动领取。
- 沿用 `saveHunt` 按提交前后累计阈值差发券的账本；跨级、一次跨多个阈值及重复保存均不会重复发券。升级与发券同时发生时，通知同时显示等级与票券奖励。
- 当前票券余额显示在英雄导航浮窗，英雄招募页保留详细数量。没有新增第二份票券状态。
- 删除橙色援军追踪入口及其耗弹、排队、进度数据；运钞僵尸的出现和实际击破奖励仍保留，战斗中不再显示概率、保底命中数或每片护甲剩余命中数。
- 主按钮固定为“自动开火”，显示开启/关闭/弹药不足状态；取消猎场暂停按钮。查看能量奖励时停止猎场输入与自动耗弹。

## 车辆与高台

- 内置 image_gen 按概念造型生成透明车身和独立炮塔。原始图、全提示词、裁切与枪口坐标见 `art/hunt-vehicle-v1`。
- 车身可见宽度 120 世界像素，占 600 像素战场宽度的 20%；炮塔像素比例为车身的 0.95，车身根节点 `(300,650)`。原图中车身安装点 `(349,299)`、炮塔旋转点 `(198,515)`、枪口 `(195,28)`。
- 子弹、散弹、激光、枪焰及瞄准线共用实际枪口变换，消除旧版 40/42 像素的不同起点。
- 用户选择 A 高台。高台使用独立透明素材，按 250 世界像素可见宽度等比绘制，底部可见锚点 `(300,800)`。边界从素材元数据计算，车尾在台面后沿内，保留可见竖直立面。
- 圆形排斥改为高台矩形排斥，按僵尸体型扩大碰撞间距；进入旧存档高台范围的僵尸会移到最近暴露边缘，并沿边行走。
- 战场画布不再藏在底部控制台后，摄像机按底部对齐。短屏的出生点和子弹上边缘反弹随可见上沿调整。
- 安全区三方案及选定方向的小车效果图见 `outputs/hunt-production-v1`。生成效果图是构图参考，不是运行截图；实际占比以上述代码尺寸为准。

## 僵尸帧动画

- 四套独立动作：普通、装甲、爆炸、巨型；每套 4 帧移动、3 帧受击、1 帧备用站姿。
- 1280×640 图集，320×320 单元。所有动作统一缩放，足底锚点 `[160,296]`；受击下肢来自同一准备帧像素，使用遮罩保留低垂手臂。移动使用真实交替腿部姿势，移除整图摇摆。
- 覆盖 kind 0–11；其余八种通过四套基础帧、功能配色、体型和原技能反馈区分。不是十二套独立重新绘制的动作。当前采用正面略俯视朝向，未新增完整八方向动画。
- 受击三帧压缩到原有 0.13 秒反馈窗口，既有移速、射速、概率、伤害及奖励数值不变。冻结停住移动帧，恢复后继续原节奏；击破淡出使用新造型，避免临时变回旧图。
- 爆炸类手套一致性已单独返工，运行资源使用 `art/hunt-zombies-v2-explosive` 的版本。v1 目录保留原始生产过程，v2 覆盖爆炸类的源图、图集、遮罩和锚点记录。
- 动作定义、完整提示词、裁切映射、固定下肢遮罩、叠图和游戏尺寸预览均保留在 `docs/art`。运行图集位于 `public/assets/hunt/zombies-v1`。
- 本地预览：`http://localhost:3010/animation-preview/hunt.html`，支持受击、暂停、慢放、冻结和逐帧查看。
