# 僵尸切图修复

2026-09-21，针对用户截图中奖励僵尸左侧橙色竖条，检查了狩猎场全部僵尸素材和 Canvas 绘制路径。

## 根因与修复范围

原始 `public/assets/hunt/zombies.png` 是 1254×1254 的角色排版图，角色轮廓并未严格落在 418×418 的九宫格里。旧代码直接按三等分采样，具体造成：

- 巨型僵尸右拳延伸到 x=450，越过 x=418 的分格边界；自己的拳头被截断，越界部分出现在奖励僵尸左侧，形成截图中的橙色竖条。
- 散射僵尸顶部起于 y=812、电弧光晕起于 y=805、冰冻罐顶部起于 y=819，均早于第三行分界 y=836。它们的顶部被切掉，并出现在第二行僵尸脚下。
- 跑步僵尸鞋底延伸到 y=419，超过第一行分界，存在小范围截断。
- 奖励僵尸脚尖和电弧光晕的包围盒在 y=805 重叠，简单扩大九宫格矩形仍可能采到其他角色。

按透明像素连通轮廓分离 9 个完整主体，将小块抗锯齿像素归属到最近主体，重排为 `zombies-isolated.png`。每格 512×512，原始逻辑格周围增加 47px 透明边距。原图保留，修复不重绘、不缩放、不删除任何非透明源像素；总共保留 755,505 个非透明像素，生成时检查每格透明采样边界。

`hunt/view.ts` 读取美术清单的 `zombiePadding`，在目标绘制区域补偿这 47px。因此人物原有大小、位置、原图像素缩放比保持不变，越界肢体得到完整展示。存活角色与死亡残影共用 `zombieSprite`，避免死亡时再次出现旧裁剪问题。命中、移动、掉落、经济和数值逻辑没有修改。

另行核对两只武器僵尸和运钞僵尸四阶段：它们的轮廓位于各自 2×1 / 2×2 单元内，运钞顶部去除 65px 的采样区也未切到帽子；没有观察到跨格串图，因此保留现有资源和绘制范围。
