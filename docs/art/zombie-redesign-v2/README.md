## 设计区分

| 系别 | 类别 | 主要识别方式 |
|---|---|---|
| 无 | 普通僵尸 | 松垮驼背、破背心、空手拖步 |
| 血肉系 | 奔跑者、巨型僵尸、奖励僵尸 | 前倾运动体态／小头巨臂／圆肚赠券与沙漏 |
| 机器系 | 装甲、散射、装甲运钞、棱镜工程、散弹工程、黑金僵尸 | 紧凑防暴甲／五向导流管／大型封闭保险柜／竖向棱镜／双管枪／开口钱匣与黑金币 |
| 元素系 | 爆炸、电弧、冰冻僵尸 | 熔火岩壳／雷纹与浮空雷晶／霜肤与冰晶扇 |

## 审阅记录

已逐张检查角色完整性、主侧背视角、系别道具和体型轮廓；所有原图均已复制到本目录。散射僵尸的五根背管与六枚胸部触点、运钞僵尸的三块胸甲、黑金僵尸的三枚箱扣均在概念图中表现。两类工程僵尸使用不同的枪口形状与背部设备；雷与冰分别采用浮空雷晶和贴身冰片。

图片表达造型意图，并非严格正交模型图或可直接接入的动画图集。体型高宽比例以美术需求文字为制作依据，独立概念卡中的角色展示大小不代表同场缩放比例。

黑金僵尸按飞书已有备注改用黑金币造型。需求中已注明：工程当前结算仍为库存弹药，此次概念制作不改变货币或返还逻辑。

远程回填记录在 publish-log.json，写入前后单元格快照分别在 sheet-before.json 和 sheet-after.json。上传脚本通过用户已授权的 Feishu API 写入图片，并读回核对 13 个独立图片标识、13 段描述及其他单元格内容。
