# 战场布局与逐帧动画更新

2026-10-08。沿用当前九位英雄、十三种僵尸的造型、存档 ID、技能数值与奖励。

## 画面布局

- 世界角色比例从 1.40 改为 1.26，缩小 10%，头像和剧情立绘不受影响。
- 响应式战场的地形及脚底位置继续铺满可用区域，角色、脚底阴影、血条、Boss 名称和刺客残影则按横纵倍率较小值等比绘制，避免矮窗口把角色压扁或高窗口把角色拉长。`scripts/test-merged-aspect.cjs` 在六种窗口尺寸中检查实际 Canvas 精灵绘制的屏幕横纵倍率，可传入内网版本 URL 验证部署产物。
- 三路中心从 75 / 195 / 315 收至 101 / 195 / 289；路间距 120 → 94，治疗与输出横向错位从 22 → 12。
- 输出位置的默认脚底 Y 从 555 下移至 585；窄屏／矮屏根据底部操作栏自动上移整组站位，保证标签完整可见，点击与拖动区域同步。
- 所有英雄、怪物、出生点、跨路支援和位移都受道路边界限制；再按每张动作图集的最大横向轮廓留出余量，防止攻击姿势或大型怪物压上路沿。

## 动作交付

共 22 个角色、44 段动作、176 帧：每角色行走 4 帧、攻击 4 帧。

| 内容 | 规格 |
| --- | --- |
| 运行图集 | public/assets/toy-v1/animations/{角色 ID}.png |
| 原始生成图 | 同目录 {角色 ID}-source.png |
| 运行图集尺寸 | 1024×512，RGBA 透明 |
| 单格尺寸 | 256×256，4 列×2 行 |
| 上排 | 行走：交替迈步、抬脚、摆臂 |
| 下排 | 攻击：准备、蓄力、出手、收招 |
| 动画锚点 | 打包基准 (128,248)，行走帧通过 frameAnchors 按躯干配准；不再随支撑脚改变主体位置 |
| 英雄方向 | 北向背面，背朝玩家；不靠水平镜像切换装备左右 |
| 怪物方向 | 朝向下方的正面三分之四视角 |
| 待机 | 使用收招站姿 |
| 死亡 | 未制作新动作，仅保留淡出 |

使用内置 imagegen，根据各角色已确认立绘生成独立动作姿势；打包脚本只裁切、等比缩放与对齐，不制作变形帧。逐角色完整提示词位于 `docs/art/toy-v1/animation-prompts/`。动画元数据位于 `shared/toy-animation-data.json`，重打包脚本为 `scripts/build-toy-animations.cjs`。

移动与攻击已删除旧的逐行平移／压缩算法。英雄攻击按原有前摇和命中时刻采样，瞬时技能在命中时进入出手帧；Boss 对应蓄力和重砸。暂停和倍速使用战斗时钟。猎场同样改用新怪物步行动作；猎场没有普通怪物主动近战的玩法，不额外改变战斗规则。

头像、招募、剧情依旧复用各角色原正面立绘。战场采用专门背面动作，二者造型对应。此次是固定视角逐帧动画，不包括八方向、独立死亡或新增技能动画。

## 验证

### 行走主体稳定性修正

旧版以每帧最低处的脚掌中心对齐，左右支撑脚交替导致整个身体横跳。现对 22 个角色的行走帧进行躯干／头部图像配准，并以收招站姿为参考，保留原有迈步和摆臂。攻击的蓄力与出手姿势保持原设计。运行时仅调整逐帧绘制原点，世界坐标、碰撞、技能数值及英雄背面朝向不变。

巨型僵尸与胖雷的源图有姿势跨越网格边界，改为按完整连通轮廓提取，避免相邻行的拳头或武器碎片混入行走帧。打包脚本自动调用 `scripts/align-toy-animation-bodies.cjs`，重新打包也会保留主体对齐。`/art-review/stability` 可播放、暂停、逐帧比较旧脚底对齐与新主体对齐，并切换站立检查停步衔接。

- 22 套图集、帧索引、英雄背面标记和比例检查。
- `scripts/test-toy-body-stability.cjs` 使用实际 ToyRenderer 的 Canvas 像素检查巨型、运钞、装甲僵尸，行走四帧及站立切换的头部平移误差均为 0 像素（256 像素图集尺度）；同时确认四个行走姿势仍各不相同。
- 第 1、4、10 关全单位道路约束与战斗结束检查。
- 原有前摇、单次命中、暂停、死亡取消测试。
- 手机及较矮窗口的布阵标签、底部遮挡、实际战斗与猎场加载检查。
- 检查截图在 `outputs/toy-animation-v2/`；动作可在 `/art-review` 切换查看。
