# 破门王美术交付与检查

## 文件
- portrait.png：768×768 RGBA。情报全身像，角色可见足底约y=704。
- boss-actions.png：2048×1024 RGBA。4列2行，512×512/格。锚点(256,456)。
- manifest.json：帧矩形、时长、源图映射、逐帧透明检查、下肢复用约束。
- prompts.md：完整生图提示和制作来源。
- portrait-source.png、boss-actions-source.png、slam-standing-source.png：三份生成原图。
- shared-lower-body.png：待机原图下肢蒙版层。
- qa-preview.png、qa-game-size.png、qa-motion.gif：原尺寸检查总览、约192像素角色格和动作序列演示。
- package_art.py：可复现规则裁切、归一化、共享下肢加工与检查。

## 已完成检查
1. 真正alpha透明，所有帧alpha范围0–255；各格四边16px安全带全透明。
2. 图集规则裁切，不按每帧包围盒拉伸。无邻格串图。
3. idle/raise/hold/slam/recover的共享骨盆、膝、靴蒙版区域像素逐帧完全一致。原始下砸蹲姿已弃用，保留源图可追溯。
4. 腰带/衣摆接缝经过肉眼检查；第一次加工发现重复腰带与靴子残影，已对齐上身并清除旧下肢。
5. 以约192px/格查看，蓄力举高→下压→回待机可读；左右行走接地脚有变化，败退为坐地姿势。

## 接入要求与边界
- 这是首版关键姿势动画，非连续高帧率动画，也不覆盖八方向。
- 固定面向屏幕下方，不允许整角色旋转追踪目标。
- 首领攻击时禁用根节点移动、行走帧和程序上下浮动。
- 攻击序列：raise 250ms→hold 500ms→slam 100ms→recover 350ms→idle 100ms，slam帧进入时仅结算一次。
- 下砸图的护栏停留在腰际，避免遮腿和破坏站定支撑；真正地面冲击圈/碎屑由战斗特效表达。
- 脚部可见像素下沿约y=454，画布地面锚点y=456保留约2px抗锯齿余量。
- 败退只播一次并保持最后一帧，不能回到战斗待机。
- 本子任务未进入运行项目；暂停、加速、死亡中断和多次伤害防护仍需主程序实际验收。
