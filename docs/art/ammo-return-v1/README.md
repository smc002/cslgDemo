# 黑金返弹：A 弹药箱爆开

使用内置 imagegen 生成，透明底源图保存在本目录；完整主提示词见 prompts.json，去背景修订见 cleanup-prompt.txt。

产物位于 public/assets/hunt/ammo-return-v1：4 张死亡姿势、3 个单发黑金弹角度、箱盖、护角和尘土，共 10 张透明 PNG。构建：node scripts/build-ammo-return-assets.mjs。

死亡动作：受击后仰 → 背箱爆裂/下跪 → 趴倒 → 静止。前左三分之四视角，反方向镜像；不循环、不回弹、不恢复待机。根节点不平移；双脚支撑点逐渐转移到双手/躯干。程序碎片、冲击环与飞弹独立叠加，不拉伸角色身体。

脚底锚点 [256,448]，画布 512×512；所有帧使用源图统一 0.62 倍缩放，不按每帧高度重新拉伸。裁切矩形记录在构建脚本。生成图实际分隔行列不同于等分网格，已按透明间隔切开并检查边界。

运行时：击杀后先保持后仰姿势 0.5 秒，沿透明轮廓叠加白金/金色辉光；随后继续原死亡序列，45ms 交叠。角色姿势时钟与弹药时钟分离：0.02 秒开始散弹，0.18 秒起 8 发弹药错峰回收，每发飞行 0.3 秒；第一发在定格结束前进入库存，0.48 秒起库存圈闪与真实返弹数飘字；2.1 秒结束。尘土延后到身体倒地阶段。所有阶段仍以游戏模拟时间驱动，全局暂停时冻结。结算仍由原有幂等返弹逻辑立即入账，动画不发奖。

验证：test-ammo-return-vfx.mjs 检查透明边界、固定画布、三种尺寸的轨迹连续性、真实目标落点和死亡不循环；test-ammo-carrier.mjs 覆盖返弹去重和存档结算。逐帧及游戏尺寸预览：/art-review/fire 的「播放爆箱返弹」，支持暂停、前进一帧。
