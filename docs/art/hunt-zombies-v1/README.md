# 猎场僵尸移动与受击帧动画 v1

2026-09-22。四套独立源关键帧由内置 image_gen 生成，按已批准造型参考图制作。没有把静态整图平移、旋转或形变伪装成移动动画。本交付目录不改项目 checkout；主代理负责复制和 renderer 接入。

## 动作定义与运行约定

| 动作 | 用途及朝向 | 准备／发力／恢复 | 地面与允许移动部位 | 循环与返回 |
| --- | --- | --- | --- | --- |
| walk | 略俯视正面，主要向画面下方行走 | 左右脚交替前伸接地、抬膝经过、换脚支撑，手臂反向摆动 | 腿脚保持完整独立源序列；程序驱动物体位移 | 0→1→2→3 循环，站定 idle 取 0 |
| hit | 受到命中时停步，保持当前左右镜像方向 | 4 准备站姿；5 躯干、头部明显后仰并抬手；6 前倾恢复 | 脚、膝、骨盆区域复用 4 的同一份像素；上身和手臂变化；根节点固定 | 不循环，0.06／0.10／0.12 秒，完成恢复行走或 idle |

受击视觉峰值为 clip 内索引 1（atlas frame 5）；这是被击反馈，不应在该时刻重复结算伤害。死亡使用现有流程并立即打断 walk/hit，本交付没有新增死亡动作。只允许左右镜像，不应旋转整个人追踪速度向量。冻结期间停帧；暂停期间停计时。移动、受击、恢复之间不得添加整图摇晃。

## 文件及坐标

- `manifest.json`：完整消费结构，4 类 archetypes 与 0–11 kind 的映射、功能配色、速度。
- `normal.png`、`armored.png`、`explosive.png`、`giant.png`：每张 1280×640、4 列×2 行、cell 320；frame row-major。
- 每类 0–3 是移动，4–6 是受击，7 是备用恢复站姿。idle 按要求取移动 frame 0。
- 统一足底锚点 `[160,296]`，是足底下方的外边界线；每帧画布一致。显示可用 `scale = desiredVisibleHeight / 236`。`visibleHeight=displayHeight=236` 是准备站姿基准，动作中头部高低保留真实变化，禁止每帧自动缩放。
- 受击骨盆/接缝锚点：normal `[160,217]`；armored `[160,215]`；explosive `[160,225]`；giant `[160,196]`。不同体形的腰线本就不同。
- walk 默认 8 FPS，奔跑 kind 1 为 11，巨型 kind 3 为 5，装甲与运钞 kind 2/9 为 6。各 kind 的 fps 在 manifest 中。

## 生产与可追溯资料

- 四份 `*-source.png` 保留未经修改的内置工具输出；`prompts.json` 保存完整四条提示词。
- `build-zombie-animations.mjs` 是生产脚本：识别 8 个独立 alpha 连通主体，避免等格裁切切断跨界手臂；按源图手工标注的骨盆中心 X 与足底 Y 注册。
- 每类所有帧共用一个缩放因子，按受击准备帧高度确定。alpha 大于 64 的连通主体入图，抑制源图很低透明度的背景色雾；保留原有透明度并将源最大 254 归一为 255。没有绘制不透明背景。
- 每类 `*-slicing.json` 保存 source bounds、源中心 X、源足底、缩放、paste 位置、像素数与固定下肢来源。每类 `*-fixed-lower-mask.png` 保存精确固定区域。面向低垂手臂的遮罩采用中央骨盆到腿的梯形，并仅在低于手掌后扩展整行，因此不把手臂横切掉。
- 从 frame 4 拷贝固定区域到 frame 5/6/7，整帧烘焙，无需 runtime 分层。
- 原图生成日志目录：`C:/Users/hy/.codex/generated_images/01a0c748-ed58-7591-b542-ea78307c78e4`。

## 验收与边界

已检查四张原图与最终图集，确认每类真实腿部姿势变化，受击具有独立后仰和恢复姿势、无裁断脚、无相邻格串图，核心服装和装备持续一致。源图爆炸类的橙色手套在左右步姿存在镜像交换，远景尺寸不影响红色罐体识别；此细节不属于装备左右手严格一致的特写资产。

`validation.json` 的自动结果：四类固定下肢 mismatch bytes 全部为 0；四边 4px 留白 alpha 总和全部为 0；walk 相邻帧下肢差异均大于 14,000 bytes。程序检查仅证明这些数值条件。

`qa-contact.png` 是全帧原尺寸棋盘底与足底/中线；`qa-hit-overlay.png` 是三受击帧半透明叠图；`qa-game-size.png` 是接近实机尺寸的各帧预览。已肉眼检查后两者，固定腿脚没有重影、上身确有位移。

**接入后仍需由主代理进行实际游戏验收**：移动→受击→移动、暂停／加速、冻结、死亡打断、左右镜像、运钞装甲阶段。素材 QA 不能替代 runtime 测试。本素材没有武器出枪口，枪口方向检查不适用。
