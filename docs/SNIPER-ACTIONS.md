# 狙击手动作样本 v4

## 先定义动作

镜头固定斜俯视，角色斜背面朝右上；保留红贝雷帽、棕色马尾、白毛领、深蓝长外套、皮带、黑靴与长狙击枪。

- 移动：低姿双手持枪，左右脚接触地面、经过支撑腿、换脚，身体轻微上下起伏。程序驱动真实世界位移，只有移动时播放步态，停下进入待机。
- 蹲射：站稳、屈膝下降、单膝触地、枪托抵肩瞄准、后坐、保持瞄准、起身、回到警戒。开火事件只在射击帧触发。
- 投雷：枪收近身体、取雷、右臂后引、前挥释放、身体前倾、手臂跟随、重新持枪。手雷在释放时从手部位置出现，沿独立弧线飞行，抵达目标后爆炸。生成图片不能包含空中的手雷或爆炸，以免出现双重表现。
- 死亡：站姿受击、躯干失衡、膝盖塌下、一手撑地、侧倒、肩/髋落地、头和枪落地、最终侧卧。终帧保持，停用移动和攻击；只有显式复活/重播会恢复。

## 由动作需求选择方案

本轮选完整人物关键姿势序列帧 + 程序位移/特效。原因是屈膝、跪地、投掷挥臂和侧倒涉及轮廓、遮挡变化，现有九个刚性部件不能可靠完成。不是把旧拼接动画烘焙成帧，也不使用整张图片旋转来假扮倒下。

每个动作先做 8 个姿势，采用不同帧时长突出预备、发力、落地。8 帧只是此次验证规格，不等同于正式动作已经达到最终流畅度。实际保持 60 Hz 位移/特效更新，图片按动作节奏切换，不用交叉淡化制造重影。

## 检查标准

1. 角色大小和身份稳定，枪械不凭空消失、四肢不多出。
2. 蹲射确实下降、弯膝；死亡终帧确实躺下并保持。
3. 跑动有真实位移；到点后不继续滑行。
4. 枪口与开火时机一致，手雷释放、飞行和爆炸分别发生一次。
5. 保留大小、暂停、慢放和逐帧检查；可复活重新测试。

仅验证当前斜背面动作，不声称新增完整多方向或已接入正式关卡。

## 预览操作

- `Move`：在两个路面位置之间移动；也可点击路面指定目标，或用 WASD 移动。左向用镜像近似，不代表新方向素材。
- `Crouch + Fire`：播放蹲下、跪姿射击、恢复站姿。
- `Throw`：抬臂投雷，显示飞行与爆炸。
- `Death`：播放侧倒并保持终帧；之后移动和攻击禁用，`Revive` 复活。
- `Play all`：依次移动、蹲射、投雷、死亡。
- `Pause`、`< Frame`、`Frame >`、时间滑条：检查独立姿势；时间滑条检查不重放已经触发的攻击事件。
- 支持 0.25/0.5/1/2 倍速度，保留 25%～200% 大小和背景切换。

Unity 菜单：`MORI > 2D Art Lab > Open Action Preview v4`。
场景：`Assets/Mori2DValidation/Scenes/SniperActions.unity`。
完整素材、生成提示词、切图元数据分别位于 `Art/Actions`、`generation-actions-v4.json`、`Data/sniper-actions.json`。

`prepare_action_metadata.py` 只读原始 RGBA 图片来计算切图/锚点，不重绘或修改原图。死亡图集两行间距不同于其他图集，使用实际透明横带作为分界，避免把上排靴子切进下排死亡帧。
