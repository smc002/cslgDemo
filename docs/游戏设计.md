# 游戏设计 · 闭环接入版

更新：2026-09-21。经用户确认，按《整体流程核对稿》实现；下面数值是首轮试玩配置，不代表两个月版本数值已定稿。

## 核心循环

物资搜刮（原三路合流）整关首通 → 黑金弹 → 禁区猎场击破僵尸 → 能源核心 → 全队共享升级、阶段招募券 → 招募与英雄培养 → 新阵容继续搜刮。累计实际耗弹独立触发橙卡挑战；内城生产黑金弹补充循环。

黑金弹、能源核心、累计实际耗弹、招募券、建材各自独立。核心不会被用于建造，也不手动分配给单个英雄。

## 搜刮与解锁

- 每关 3 波，通关奖励 120 + min(20,关卡−1)×15 黑金弹。失败/重打已通关内容不重复发奖励。
- 自动移动、普攻和技能，优先处理当前战斗路的敌人与治疗。清完一路后，该路英雄走向最近仍有敌人的路支援，支援后可以攻击和治疗该路单位；原布阵归属不变，下一波前归队。可拖动英雄交换、选一个已拥有英雄再点击位置替换，也支持键盘换位和一键配队。
- 某路没有可承伤英雄时，剩余僵尸向仍有可承伤英雄的路转攻，不再走出画面后直接删除。刺客依然不被敌人选为目标，因此仅剩刺客时按失败处理。
- 开局：铁壁队长、医疗兵、无人机手，开放左路 3 格。
- 第 1 关：禁区猎场开放；猎场与招募核心教学。
- 第 2 关：第二路、内城；获得大刀战士/吉他手/刺客援军，免费修复一级建材工坊并获得 100 建材。
- 第 4 关：第三路；获得重机枪手/牧师/狙击手援军。
- 每 5 关为首领关，第三波前排精英有 2.5 倍血量；抵达该关自动停在布阵，小窗提示返回并手动挑战。当前复用精英外观，没有新做首领造型。
- 关内保留损血与阵亡，进入下一关或重试恢复整队。刷新/重新布阵从当前未通关关卡第一波重新开始。
- 在其他游戏页面继续同一个搜刮模拟；失败停止，全员配置成长后可重试。浏览器关闭或系统挂起不离线推关。

## 猎场

复用旧猎场射击、反弹、奖励/爆炸/散射/电弧/冰冻僵尸、武器奖励、转场与运钞僵尸规则。库存实际扣弹和结算一次提交。免费派生弹不重复累计库存耗弹。

能源核心总量是猎场所得总积分；每升一级需要当前等级×200核心，自动升级、余量保留。原版每发实际子弹的少量参与核心也保留。每累计 200 核心自动到账 1 招募券，不要求手动开箱。

实际耗弹每 1000 发积累一次运钞僵尸挑战资格，按旧版装甲阶段及击破机制领奖，不能直接跨过战斗拿橙卡。原版高级倍率准入库存（×5/×20/×100 对应 500/2000/10000 发）暂保留。不同猎场地区的开关也保留。

## 英雄

统一九个 heroId，依次对应战斗精灵、技能、卡池、档案和编队。初始品质：

| 品质 | 英雄 |
| --- | --- |
| 蓝 | 铁壁队长、医疗兵、无人机手 |
| 紫 | 大刀战士、吉他手、狙击手 |
| 橙 | 暗影刺客、重机枪手、牧师 |

抽卡蓝/紫/橙概率 70%/25%/5%，同品质均分，无新加保底。单抽/十连消耗 1/10 券。英雄第一次获得即拥有，之后每份重复卡增加 1 份进度。

试玩每品质 1～3 星：1→2 星消耗 1 份重复，2→3 星消耗 2 份，满星进阶下一品质消耗 3 份并回到 1 星。蓝→紫→橙→红，红三星封顶。没有跨 heroId 消耗，也没有同一英雄以不同初始品质入池。

战斗生命、伤害、治疗乘数 = [1 + (共享等级−1)×0.16] × [1 + 品质档次×0.18 + (星数−1)×0.10]。品质档次蓝/紫/橙/红=0/1/2/3。培养升级即时影响正在运行的英雄，生命按原比例换算，不复活已阵亡英雄。战前换阵在下次出发时生效。

## 内城与断弹兜底

- 工坊每 30 秒生产 10×建筑等级建材；工厂每 45 秒生产 15×建筑等级黑金弹。
- 建造或升级消耗 100×目标等级建材，试玩上限 10 级，无施工队列。升级先结算旧等级产物，再开始新周期。
- 手动领取，离线累计最多 20 批，达到容量后不会无限补发。关闭页面也可按时间戳生产。
- 黑金弹不足 5 发、已完成第一关时可从设置领取 80 发应急补给。总共 3 次、每次冷却 3 分钟。首轮关卡较温和，内城在第二关开放。
